# DB Graph

DB Graph — локальный веб-инструмент для исследования SQLite-баз. Он читает
схему базы в режиме read-only и превращает её в интерактивную ER-диаграмму:
показывает таблицы, колонки, ключи, индексы и связи, а также даёт быстро
просмотреть строки без SQL-клиента.

Проект полезен, когда нужно быстро понять незнакомую SQLite-базу, проверить
внешние ключи или наглядно показать структуру данных. Backend написан на
FastAPI, frontend — на vanilla JavaScript и SVG; Node.js и сборка не нужны.

## Возможности

- карточки таблиц с PK, FK, UNIQUE, NULL-маркерами, типами и числом строк;
- crow's-foot связи, включая 1:1, nullable, составные и self-reference FK;
- четыре раскладки графа: force, слои, сетка и круг;
- поиск, масштабирование, панорамирование и перетаскивание карточек;
- детали таблиц и связей, исходный SQL и превью первых 15 строк;
- поддержка VIEW и «ghost»-таблиц для битых FK-ссылок;
- встроенная воспроизводимая демо-база интернет-магазина;
- загрузка `.db`, `.sqlite`, `.sqlite3` и `.db3` до 256 МБ.

## Быстрый старт

Нужен Python 3.10 или новее.

Linux/macOS:

```bash
chmod +x run.sh
./run.sh
```

Windows PowerShell:

```powershell
.\run.ps1
```

После запуска откройте <http://localhost:8123>. Скрипт создаст `.venv`,
установит зависимости и при первом запросе сгенерирует `data/shop.db`.

Ручной запуск:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows:     .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8123
```

## Как пользоваться

1. Откройте встроенное демо или нажмите «Открыть .db/.sqlite».
2. Выберите раскладку в верхней панели.
3. Кликните по таблице или связи, чтобы увидеть детали.
4. Используйте колесо для зума, drag по фону для панорамы и `F`, чтобы
   вписать граф в экран.

По умолчанию backend разрешает только демо-базу и файлы, загруженные через
интерфейс. Для локальной разработки можно разрешить API читать произвольный
путь на компьютере:

```bash
DBGRAPH_ALLOW_LOCAL_PATHS=1 ./run.sh
```

В PowerShell перед запуском используйте
`$env:DBGRAPH_ALLOW_LOCAL_PATHS = "1"`. Не включайте этот режим на сервере,
доступном другим пользователям.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/schema` | схема демо-базы |
| `GET` | `/api/schema?refresh_demo=1` | пересоздать демо и вернуть схему |
| `GET` | `/api/schema?path=…` | схема файла; требует разрешённый путь |
| `GET` | `/api/sample?path=…&table=…&limit=…` | превью строк таблицы или VIEW |
| `POST` | `/api/upload` | загрузить SQLite-файл и вернуть схему |
| `GET` | `/healthz` | проверка работоспособности |

## Ограничения и приватность

- приложение поддерживает только SQLite;
- подсчёт строк выполняет `COUNT(*)`, поэтому огромные таблицы могут
  обрабатываться заметно дольше;
- загруженные базы сохраняются локально в `data/uploads/` и не попадают в Git;
- приложение рассчитано прежде всего на локальный запуск и слушает только
  `127.0.0.1` в поставляемых скриптах.

Перед публикацией собственной базы убедитесь, что в ней нет персональных
данных, токенов и другой чувствительной информации.

## Идеи развития

- PostgreSQL/MySQL через SQLAlchemy Inspector;
- экспорт в PNG/SVG и minimap;
- группировка таблиц и раскраска связанных кластеров;
- виртуализация карточек для очень больших схем.
